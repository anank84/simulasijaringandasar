Petunjuk Penggunaan Virtual Network Lab Pro

1. Menambahkan & Memindahkan Perangkat

Tarik (drag) perangkat dari panel kiri ke area kanvas, atau cukup klik ikon perangkat untuk menambahkannya secara cepat. Klik dan geser perangkat di kanvas untuk mengatur tata letak topologi.

2. Menghubungkan Kabel Jaringan

Pilih jenis kabel pada kategori Connections (misal: Copper Straight-Through untuk PC ke Switch, Cross-Over untuk PC ke PC atau Switch ke Switch). Klik perangkat pertama, pilih port, lalu klik perangkat kedua dan pilih port tujuan.

3. Konfigurasi IP Address & Gateway

Klik perangkat untuk membuka panel Properti di sebelah kanan, atau klik ganda pada PC/Laptop untuk membuka jendela Desktop > IP Configuration. Pastikan IP berada pada subnet yang sama untuk komunikasi lokal, dan atur Default Gateway untuk komunikasi beda jaringan melalui Router.

4. Pengujian Konektivitas (PING & Terminal)

Gunakan tombol Simulasi PING (PDU) lalu klik komputer sumber dan tujuan untuk melihat animasi paket bergerak melalui kabel, Switch, dan Router. Anda juga dapat membuka Terminal CMD untuk menjalankan perintah ipconfig, ping, tracert, dan arp -a.
